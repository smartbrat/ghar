Preferred default for new tenants. Full-width image band + white rounded card lifts over image bottom + logo tile straddles seam via margin-top:-28px. Currently on teearch, avirahi, godrej, scarlet, horizon. Mobile-flag: body[data-past-image]. Registry: hero.brand_variants.split.

05 · about.default

About — default (lede + paragraphs)

Baseline for most brands. Display-scale lede + paragraphs unfold beneath. Section ID #about is canonical (was #story on developer family — normalised 2026-08-31). Registry: about.brand_variants.default.

We build things that outlive the developer.

First paragraph — the practice's manifesto. What we do, who we do it for, the belief that ties it all together.

Second paragraph — the body of work. Locations, project types, delivered years.

Third paragraph — the team, the leadership, the succession story.

25 · contact.light

Contact — light warm-cream contained card

Second redesign 2026-08-31 — was a full-bleed warm-cream panel; now a CONTAINED rounded card. On desktop: max-width 720px, centered inside the section, breathing space either side (below the full site container width). On mobile / tablet-portrait (≤899px): card stretches to fill the site container so it aligns with every other section. Warm-cream fill lives on the CARD, not the section — section itself is transparent. Currently: teearch, avirahi, horizon. Registry: contact.brand_variants.light.

27 · [hidden] auto-hide

Hidden state — how empty sections collapse

The load-bearing rule from TEMPLATES-USAGE.md. Every section that can be absent ships with a hidden attribute + a CSS rule that collapses it. Never delete the section node. The section IS the DOM contract; the hidden state is what varies.

28 · Modifier stacking

Section modifiers — cross-cutting classes that stack

--tight (reduced padding) · --attached (no top boundary) · --minor (de-prioritised) · --dark (dark panel) · --seamless-wrap (flows into next section). Modifiers stack on any variant. See design-system catalog Pattern 4.
